# wfw-translator

A small Streamlit app for translating passages and showing a word-for-word breakdown. It defaults to Korean-to-English, but supports a range of source and target languages through Google Translate.

The live app can be tested at:

https://wfw-translator.streamlit.app/

## Local use

Install the project dependencies, then run:

```bash
streamlit run app.py
```

The app requires network access because translations are requested from Google Translate.
